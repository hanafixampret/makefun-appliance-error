One line: the funniest honest error message an appliance could show. A fridge, in its own flat, put-upon voice, reports the door left open — and the consequence for the milk.

## Entry

> Error: the door has been open for 6 minutes. I am a fridge, not a window. Your milk is now soup.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`.
